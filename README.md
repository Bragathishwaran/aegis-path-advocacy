# AegisPoint Advocacy

Special Education Advocacy and IEP Consulting Platform.

## Overview
AegisPoint Advocacy provides professional special education advocacy, IEP reviews, 504 plan consultations, and parent support to ensure children with disabilities receive the tailored educational accommodations they deserve.

## Features
- **Responsive Web Pages**: Home, About, Services, Pricing, Blog, Contact, and Parent Portal.
- **Form Validation**: Client-side and server-side validation for consultations and newsletter subscriptions.
- **Accessible & Tested**: Full test suite verifying validation logic.
- **Tailwind CSS & Modern UI**: Built with custom typography, responsive design, and accessible components.

## Getting Started

### Installation
```bash
npm install
```

### Build CSS
```bash
npm run build
```

### Run Tests
```bash
npm test
```

### Start Server
```bash
npm start
```
